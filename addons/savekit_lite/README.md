# GodotSaveKit Lite — 1.0.1

A small, free Dictionary-to-JSON save helper for Godot 4.x. One implicit save, four static methods, no autoload or scene restoration.

## Install
1. Copy `addons/savekit_lite/` into your project's `res://addons/savekit_lite/`. Retain the supplied LICENSE notice when redistributing.
2. Let Godot import the scripts. In **Project > Project Settings > Plugins**, enable **GodotSaveKit Lite** if you want the plugin marked enabled. The plugin is intentionally empty: enabling it is optional and does not register services or change runtime behavior.
3. Use `GSKLite` directly, or preload `res://addons/savekit_lite/savekit_lite.gd`. The included `project.godot` and `demo/` are a standalone example, not required in your game.

## Usage
Attach this script to a Node after installing:

```gdscript
extends Node
const SaveKit = preload("res://addons/savekit_lite/savekit_lite.gd")
var level: int = 1

func _ready() -> void:
    var error: Error = SaveKit.save_data({"level": 2, "inventory": ["key"]})
    if error != OK:
        push_error("Save failed: " + error_string(error))
        return
    var result: Dictionary = SaveKit.load_data()
    if result.error == OK:
        level = int(result.data.get("level", 1)) # Caller applies loaded state.
    else:
        push_error("Load failed: " + error_string(result.error))
    print("Save file exists: ", SaveKit.has_save())

func erase_progress() -> void:
    var error: Error = SaveKit.delete()
    if error != OK and error != ERR_DOES_NOT_EXIST:
        push_error("Delete failed: " + error_string(error))
```

| API | Result |
| --- | --- |
| `GSKLite.save_data(data: Dictionary) -> Error` | `OK` after replacement, otherwise validation/filesystem error |
| `GSKLite.load_data() -> Dictionary` | Always `{ "error": Error, "data": Dictionary }`; failure data is `{}` |
| `GSKLite.has_save() -> bool` | Primary-file existence only, not validity |
| `GSKLite.delete() -> Error` | Removes primary and owned temp; `ERR_DOES_NOT_EXIST` if neither exists |

Always check `result.error`: an empty Dictionary is a valid successful save. Missing load returns `ERR_FILE_NOT_FOUND`; invalid data returns `ERR_INVALID_DATA`; unsupported envelope versions return `ERR_UNAVAILABLE`. A recognized future version also blocks overwrite. Explicit save may replace corrupt data. Load does not modify corrupt files. Delete can partially complete if an I/O error occurs.

## Scope and limits
- Fixed file: `user://godot_save_kit_lite.json`, envelope `{"version":1,"data":{...}}`. No configurable paths, slots or schema version.
- Validates JSON-safe trees: null, booleans, finite numbers, strings, arrays and String-keyed dictionaries. Rejects cycles, unsupported Variants, depth over 64 and files/serialized envelopes over 8 MiB. Convert vectors/resources to ordinary JSON data yourself.
- Writes, flushes and validates a sibling `.tmp`, then renames over the primary without deleting it first. This is safe replacement, **not a power-loss durability guarantee**. Rename errors are returned; there is no delete-then-rename fallback.
- Synchronous, main-thread, single-writer use only. Load ignores stale temp files. No encryption, cloud sync or automatic scene/object serialization.
- JSON can change numeric types/precision; store exact large IDs as strings. Duplicate keys follow Godot's JSON parser behavior, not explicit duplicate-key rejection.
- No multiple slots/listing, `.bak` recovery, quarantine, migration hooks, autosave, slot metadata, settings service or input rebinding. Lite save format is not promised compatible with the full kit. See FEATURES-COMPARISON.md in the standalone Lite project repository for the feature comparison.
